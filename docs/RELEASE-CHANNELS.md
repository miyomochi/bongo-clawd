# 发布通道与验收

稳定版 0.3.0：可选的手臂方向感（默认开，可切回原版），正式采用四种戳一戳。

beta 0.3.1-beta.1：稳定版功能加试验更新服务；每日自动检查默认关闭，明确提示不稳定。共用已有设置与安装目录，二者替换使用，不支持同时运行。稳定版的更新入口永远不读取 beta 元数据。

发布分支会触发 Windows CI，产出便携 ZIP、安装包 ZIP 和 SHA256SUMS；CI 仅构建，不会自动发布或更改 latest.json。源码测试通过不代表已在 Windows 运行验收。

## Windows 手动验收

1. 安装并启动：设置 → 外观切换手臂方向感，重启检查持久化；近远按键与双手快速打字。
2. 身体轻点四种回应，长按、拖拽、右击不误触发；真实打字打断互动，身体内移动不操作鼠标；离开后正常鼠标联动。
3. 镜像、缩放、暂停、睡眠、装饰和右键菜单正常。
4. beta 单独验证：自动开关、每日一次、今日不再提示、手动绕过今日记录、网络失败关闭后恢复；下载失败、哈希失败、安装取消与成功重启。失败字样为放大的红色 ERROR。
5. 两套安装包验证通过后，使用真实构建的 ZIP 哈希更新对应元数据；稳定元数据只包含稳定版本。
