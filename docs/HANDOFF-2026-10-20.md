# Bongo Clawd · 2026-10-20 交接

稳定版 0.3.0：手臂方向感在外观设置中可关闭，回到原有小短手；四种戳一戳正式接入，身体轻点、右击、长按与拖拽区分，身体内指针输入不触发使用鼠标动画。稳定程序源码留在 main。

Beta 0.3.1-beta.1：稳定版功能加更新流程试验。每日首次启动检查默认关闭，在设置 → 系统开启；手动检查忽略当天检查和不再提醒记录。更新日志随版本元数据拉取；下载以真实字节显示进度并核对 SHA256，再交给 Windows 安装向导。重启后核对实际版本，成功挥官方梗魔法棒；失败晕晕并显示放大的红色 ERROR，关闭提示后恢复输入。

两版共用应用标识、安装目录和个人设置，替换使用。Beta 读取 main/updates/beta.json；稳定版读取 main/updates/latest.json，稳定用户不会被自动推送 beta。

源码：release/stable-0.3.0 与 release/beta-0.3.1-beta.1。发布方式沿用仓库 downloads ZIP 和对应元数据。不要把 beta 后端或自动更新设置合入 main 的稳定应用；main 可以承载 beta 运行包、文档和 beta 元数据。

稳定版已通过 94 项 Node、19 项 Rust 核心检查与 Windows MSVC/NSIS 构建；Beta 已通过 98 项 Node、21 项 Rust 核心检查，最终构建及提取结果见 docs/BETA-0.3.1-beta.1.md 和对应 Actions。原始角色 SVG 几何保留，手臂与互动通过可选 renderer/input 扩展加载。

主要文件：web/core/clawd-reach.js、clawd-reactions.js；web/desktop-renderer.js 负责原生输入和点击/拖拽仲裁；src-tauri/src/preferences.rs 保存 directionalArms。Beta 增加 update_service.rs、updates.rs、system.rs、update-extract.ps1、update-launch.ps1、web/core/clawd-update-visuals.js 和更新弹窗页。

构建修正：Python 显式 UTF-8/LF，NSIS Windows 负载路径用反斜杠并指定 UTF-8；chrono 只启用 clock，避免默认 wasm 特性改变锁文件；MessageBeep 来自 System::Diagnostics::Debug，需要相应 windows-sys feature。
