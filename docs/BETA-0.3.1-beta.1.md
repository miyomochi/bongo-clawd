# Bongo Clawd 0.3.1-beta.1 · 不稳定试验版

包含稳定版的手臂方向感开关和四种戳一戳。额外提供每日首次启动检查（默认关闭）、更新日志、今日不再提示、下载进度、SHA256 校验、安装向导交接和升级成功重启反馈。

## 动画

检查：敲键盘与蓝色半透明浮屏；发现新版：举灯泡和提示音；下载：实际进度；成功：挥魔法棒庆祝；失败：晕晕、放大的红色 ERROR，关闭错误提示后恢复正常。

## 使用

设置 → 系统 → 每天自动检查更新 · Beta。手动检查仍可使用，不受当天记录限制。只检查和提示，确认后才下载、安装。Beta 与稳定版共用安装目录及个人设置，替换使用，不同时运行。想回到稳定版，退出小蟹后安装稳定版即可。

Beta 读取独立的 updates/beta.json；稳定版仍只读取 updates/latest.json。安装 beta 不会改变其他稳定版用户的更新通道。

## 检查与限制

98 项前端和模拟流程检查、21 项 Rust 核心检查通过；Windows MSVC release 与 NSIS 编译通过；Windows PowerShell 实际提取安装程序的 SHA256 一致，错误条目被拒绝；运行包 ZIP、哈希与便携 EXE 格式检查通过。

CI：https://github.com/miyomochi/bongo-clawd/actions/runs/39447043102

真实 Windows 桌面上的每日启动、网络下载、安装取消与升级重启仍需用户实机验证。本版不稳定，愿意尝鲜再使用。首个 beta 的完整更新动画可通过之前的离线预览体验；真实升级到后续 beta 才能验证整套安装及成功反馈。
