# 0.4.0-beta · 新服饰与待机彩蛋

继承上一 Beta 的自动检查更新、日志、下载进度、SHA256 校验与安装向导升级机制，加入这一批新功能。

- 衣柜增加独立翻页按钮，到头变灰；新增牛仔帽、侦探帽。
- 牛仔小蟹抬起塑料玩具枪，弹出玫瑰，再收花藏好：“老板，来杯牛奶。”
- 侦探小蟹慢慢检查键盘，再举放大镜放大一只眼：“发现线索了。”
- 待机时睡觉、偷偷打游戏随机二选一。被发现后关掉浮屏、跳一下，＞＜眼、❗气泡，侧边挥手两轮收好手柄。
- 吹泡泡时右手照常工作；快速敲击时慌张收环，剩余泡泡飘完。
- 魔法棒施法，把小蟹变成平面四脚立绘；快速敲击时提前用烟雾恢复。键位映射与计数保持工作。

仍为 Beta，尚待 Windows 实机验收。自动检查默认关闭，可在设置中开启。升级通过下载安装包、运行安装向导并重启完成。

建议保留旧 Beta，从旧客户端“检查更新”开始验证整条升级流程。不要先覆盖安装本版，再把它当成旧版更新成功。

附件中的 Setup.zip 为安装包，Windows-x64.zip 为便携版；Source code 为源码。需要系统 Microsoft Edge WebView2 Runtime。
