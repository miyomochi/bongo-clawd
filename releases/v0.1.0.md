# 0.1.0 · 初版历史归档

第一个稳定归档：一只响应全局键盘与鼠标输入的 SVG 像素小蟹。

支持左右手与键鼠同时使用、按键亮灯、快敲冒汗与喘息恢复、随机眨眼、探头、伸懒腰、睡眠、惊醒和心虚假敲；提供设置页、托盘菜单、大小调节、置顶与上下栏显示设置。

本版尚未加入戴墨镜、开心 / 梦境气泡及头部装饰。新增动画将在兼容检查后进入后续版本。

## 运行

Windows 10 / 11 x64，系统需有 Microsoft Edge WebView2 Runtime。下载附件 Bongo-Clawd-Lite-Windows-x64.zip，完整解压后双击 Bongo-Clawd-Lite.exe。

本次附件沿用已试用的 0.1.0-preview.1 原始构建，内部版本号保留，未重新编译。用户已反馈日常使用、睡眠、加速和惊醒正常；多屏、不同 DPI 及长时间运行尚未完整验证。
