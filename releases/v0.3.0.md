# 0.3.0 · 稳定版

- 新增「手臂方向感」外观开关，按键按远近、内外分区，手臂只做轻微伸缩。幅度太大像面筋，观感怪；这版稍微改善打字感，但不多。喜欢原来更小短手的，可以关掉沿用原动画。
- 正式加入戳一戳：歪头挠挠、害羞爱心、果冻弹弹、眯眼摇摇唱歌（动作和音符）。
- 轻点身体触发回应，右击打开菜单，移动超过阈值才拖拽；点击身体不会触发操作鼠标的动画。
- 稳定版保留原来的手动检查更新。自动检测、下载和安装动画仅在 beta 试验，不稳定，愿意尝鲜可另行选择。
