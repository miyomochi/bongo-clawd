Bongo Clawd · 0.3.0

本项目的安装包和程序目前没有 Windows 数字签名。系统可能提示未知发布者、拦截启动或显示“Windows 已保护你的电脑”。请确认来源并核对校验值后自行决定是否运行；便携版也可能出现相同提示。

1. 先从托盘菜单完全退出正在运行的旧版小蟹。
2. 安装版：运行 Setup.exe，可选择安装目录，默认创建桌面快捷方式。便携版：完整解压本文件夹，双击 Bongo-Clawd.exe。
3. 右侧三个方块：设置、装饰、暂停。暂停后变为中间的小卡片，点一下继续，按住可拖动。
4. 设置分外观、休息、统计、系统四页；关闭设置窗口后恢复工作。
5. 装饰可选天蓝耳机、猫耳耳机、小苗、小黄鸭，选中预览，「戴上」保存，「取消」还原。
6. 侧边按钮可在设置或右键菜单隐藏。隐藏后仍可右键小蟹或使用托盘找回。

台词在头顶短暂出现；动画的想法泡出现时，普通台词让位，结束后只显示仍有效的最新一句。
统计默认关闭；开启后键盘下方的深色底板显示敲击次数与近 60 秒次数/分，万以上按 x.x万 缩写。
统计只在内存中累计，完全退出或关闭统计清零；隐藏到托盘仍累计，暂停/调整期间不计入。
长按连发只计一次，鼠标和模拟敲击不计入。不读取或保存文字、剪贴板，不上传键鼠输入。

默认轻微呼吸，空闲 90 秒睡觉，设置中可调整。保留墨镜、开心气泡、做梦和四款头饰。
Windows 10/11 x64，需要系统 Microsoft Edge WebView2 Runtime。
本版通过自动化检查与 Windows 交叉编译，新增功能仍需 Windows 实机试用。
设置与旧 Lite 版共用原路径；保留旧运行包用于回退。详见 VALIDATION.md。

本次微调：侧向纵深按钮与按压回弹；设置在小蟹所在屏居中；装饰框原地显隐；惊醒装忙延长1秒；快敲进入等待600毫秒、退出缓冲2400毫秒；换装台词在确认且动作结束后播放。

菜单说明：「显示小蟹」用于从隐藏状态唤回；已经显示时通常没有可见变化。当前右键与托盘共用菜单，后续会精简重复项。

0.2.1：安装向导支持选择目录；运行中再次双击应用图标会唤出小蟹和设置菜单；每次重新启动，小蟹回到主屏幕可用区域的右下角。

外观页或右键菜单可切换「镜像工位」：整个工位及操作按钮换边，统计和气泡中的文字保持正常阅读方向。
系统页：开机自启动、检查更新、卸载。登录自启只显示小蟹，不弹出设置；检查更新后可确认打开浏览器下载；安装版卸载保留设置，便携版退出后删除文件夹即可。

0.3.0 稳定版：正式加入戳一戳；设置 → 外观 → 手臂方向感，可切回原来的小短手。自动更新试验只在 beta 提供。

修复戳一戳不响应问题，添加新的临时图标。互动触发后完整播放；期间真实按键照常统计，动画结束后恢复联动。
